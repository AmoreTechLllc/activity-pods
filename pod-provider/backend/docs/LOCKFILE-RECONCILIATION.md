# Backend lockfile reconciliation

The backend `yarn.lock` was regenerated by GitHub Actions on Ubuntu 24.04 with Node 22 and Yarn 1.22.22 after normalizing legacy public GitHub SSH URLs to HTTPS. The generated lockfile was then immediately regenerated a second time in the same job and compared byte-for-byte to verify stability.

The temporary one-shot workflow used for regeneration was removed before this branch was prepared for merge. The intended repository change is the generated backend lockfile only; this note exists on the temporary validation branch and should not be merged with the lockfile if a lockfile-only PR is desired.
